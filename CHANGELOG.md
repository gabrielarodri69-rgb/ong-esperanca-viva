# Changelog

Todas as mudanças notáveis deste projeto são documentadas neste arquivo, seguindo o padrão [Keep a Changelog](https://keepachangelog.com/) e [Versionamento Semântico](https://semver.org/).

## [1.0.0] - 2026-09-26

### Adicionado
- Documentação técnica completa (README.md) com stack, estrutura de pastas e instruções de execução.

## [0.1.0] - 2026-09-26

### Adicionado
- Estrutura HTML5 semântica para as views Início, Projetos e Cadastro.
- Design System em CSS3: tokens de cor, tipografia, espaçamento, Grid de 12 colunas e 5 breakpoints responsivos.
- SPA em JavaScript vanilla: roteamento por hash, sistema de templates orientado a dados, validação de formulário com feedback em tempo real, persistência via localStorage.
- Código modularizado em `templates.js`, `storage.js`, `validacao.js` e `router.js`.
- Integração com a biblioteca IMask para máscaras de input (CPF, telefone, CEP).
